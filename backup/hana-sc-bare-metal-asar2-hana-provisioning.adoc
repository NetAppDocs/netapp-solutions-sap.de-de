[[hana-host-configuration]]
== HANA Hostkonfiguration

Vor der Einrichtung des Hosts müssen die NetApp SAN Host Utilities von der  http://mysupport.netapp.com/["NetApp Support"] Site heruntergeladen und auf den HANA-Servern installiert werden. Die Dokumentation der Host Utilities enthält Informationen zu zusätzlicher Software, die abhängig vom verwendeten FCP-HBA installiert werden muss.

Die NetApp SAN Host Utilities können ebenfalls verwendet werden, um die WWPN der Hostadapter zu erhalten, die für die Konfiguration des Host-Mappings auf dem Speichersystem erforderlich sind.

....
sapcc-hana-tst-02:~ # sanlun fcp show adapter
host20             WWPN:100070b7e40bbadb
host21             WWPN:100070b7e40bbadc
....


[[multipath-configuration]]
=== Multipath-Konfiguration

. Auf jedem Server wird der Linux-Befehl rescan-scsi-bus.sh -a ausgeführt, um neue LUNs zu erkennen.
. Der Befehl `sanlun lun show` wird ausgeführt und es wird überprüft, ob alle benötigten LUNs sichtbar sind. Die Ausgabe zeigt, dass die LUNs und die zugehörigen Gerätedateien vier FC-Pfade vom Host zu den Speicherkontrollern aufweisen.

[[hana-installation]]
=== HANA-Installation

Die HANA-Installation kann nun ausgeführt werden.


NOTE: Bei der beschriebenen Konfiguration wird das Verzeichnis /usr/sap/BM1 auf der OS-Festplatte gespeichert. Wenn /usr/sap/BM1 auf einer separaten Festplatte gespeichert werden soll, muss eine zusätzliche LUN auf dem Speichersystem konfiguriert werden.
