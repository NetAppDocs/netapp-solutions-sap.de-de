= SAP HANA-Sicherung und -Wiederherstellung mit NetApp Storage Systems und Commvault Software
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Dieses Dokument beschreibt den Entwurf einer NetApp und Commvault Lösung für SAP HANA, die die Commvault IntelliSnap Snapshot-Management-Technologie und NetApp Snapshot Technologie umfasst. Die Lösung basiert auf NetApp Storage und der Commvault Data Protection Suite.

Autoren: Marco Schoen, NetApp; Dr. Tristan Daude, CommVault Systems
