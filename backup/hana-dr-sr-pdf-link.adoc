= Technischer Bericht: SAP HANA Disaster Recovery with Storage Replication
:hardbreaks:
:allow-uri-read: 
:nofooter: 
:icons: font
:linkattrs: 
:imagesdir: ../media/


[role="lead"]
Dieses Dokument bietet einen Überblick über die Optionen für den Disaster-Recovery-Schutz für SAP HANA. Es enthält detaillierte Informationen zur Einrichtung und eine Anwendungsfallbeschreibung einer Disaster-Recovery-Lösung mit drei Standorten, die auf synchroner und asynchroner NetApp SnapMirror Storage-Replikation basiert. Die beschriebene Lösung verwendet NetApp SnapCenter mit dem SAP HANA Plug-in zur Verwaltung der Datenbankkonsistenz.

Autor: Nils Bauer, NetApp
